## Ограничения проверки

- Browser-only открытие `file://…/index.html` — BLOCKED: политика встроенного браузера
  запрещает локальные HTML URL. Обход не предпринимался. Проверки структуры,
  локальных ссылок, контрольных сумм и медиаданных выполнены на файловой системе.
- Повторная пересборка web-образа остановлена на длительной сетевой установке npm;
  использован существующий образ с теми же зависимостями. Next production build
  выполнен отдельно и прошёл. Сборка теперь использует `.next-build`, чтобы не
  повреждать работающий dev-сервер.

Первый диагностический анализ выявил потерю начала вопроса при разборе строк
YouTube с пустой верхней строкой отображения. Парсер исправлен и покрыт регрессией;
новый анализ использует 1473 очищенные реплики с исходными временными границами.
Диагностические запуски остались в истории. Запуск с несовпадающей версией промпта
отклонён обработчиком, а не выполнен под неверным снимком настроек.
