# Расшифровка перед загрузкой видео

Обычный запуск YouTube-ссылки сначала использует сохранённую расшифровку либо
получает только субтитры/метаданные. Видеофайл не является условием смыслового анализа.
Отдельного режима и переключателя нет.

Если исходник уже сохранён, после анализа можно продолжить существующий рендер.
Если исходника нет, результатом запуска становятся эпизоды с таймкодами:
Job.progress.media_deferred=true, ревизии со статусом analyzed, actual_duration_sec
и MP4 URL остаются null. Job.counts.analyzed отделён от counts.ready (проверенные MP4).

В snapshot расшифровки есть key, version, duration_limit_sec и timing_note.
Граница доступного текста не записывается как измеренная Source.duration_sec.
Правки диапазонов проверяются по измеренной длительности либо по консервативной
границе расшифровки; при отсутствии исходника повторяется только проверка смысла.
Повтор обычного запуска также использует сохранённый текст без скачивания видео.

GET /jobs/{id}/analysis/download сохраняет текущую выбранную разметку в JSON.
Экспорт MP4 ZIP для media_deferred возвращает понятный 409. UI показывает разметку,
контекст и ссылки YouTube с таймкодами, без обещания готовых MP4 или вечного ожидания плеера.

Для fytyk6VhlMI текст штатной панели YouTube (1660 реплик до 3:44:51) сохранён в MinIO;
результат реального GPT-6 Astra medium перенесён в то же задание приложения.
Если YouTube не отдаёт текст загрузчику и в кэше его нет, приложение сообщает об
ошибке доступа к расшифровке, не переключаясь скрыто на скачивание видео.
